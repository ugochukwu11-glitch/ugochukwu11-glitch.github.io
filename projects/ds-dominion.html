InsightBot

A multilingual, data science–driven news aggregation and insight platform designed to extract, structure, and visualize global news trends at scale.

Problem Definition

The modern information landscape is saturated with news content published continuously across hundreds of platforms, regions, and languages. While access to information has increased, the ability to extract meaningful insights from this volume of data has significantly declined.

Readers, analysts, and decision-makers face three core challenges:

  • Information overload from unstructured news sources
  • Inconsistent formats, languages, and publishing styles
  • Lack of high-level insight into emerging trends and topics

The problem InsightBot addresses is not simply data collection, but transforming raw, unstructured web news into structured, analyzable, and visual insights that support faster understanding and decision-making.

Design Specifications

InsightBot was designed with the following system requirements in mind:

  • Automated extraction of news headlines and article bodies
  • Support for multiple languages and regions
  • Pattern-based generalization rather than site-by-site hardcoding
  • Structured storage suitable for analytics and visualization
  • Clear separation between data extraction, storage, and presentation

To meet these goals, the system avoids heavy browser automation and instead relies on intelligent HTML parsing, heuristic link validation, and scalable rule-based extraction strategies.

Data Sources & Test Data

The project uses real-world news websites as its primary data source. Two datasets were created in alignment with the SRS:

  • Training Set: 40 known news websites used to refine scraping heuristics
  • Testing Set: 10 unseen websites used to evaluate generalization

Extracted fields include:

  • Article URL
  • Headline (title)
  • Full article body
  • Publication date
  • Article length
  • Source domain

This approach ensured the system was evaluated under realistic, unpredictable web conditions.

System Architecture

InsightBot follows a modular pipeline architecture:

  • Web Scraper: Extracts links and article content using heuristics
  • Validation Layer: Filters non-article pages and low-quality content
  • Storage Layer: Structured persistence in MySQL and CSV
  • API Layer: Flask endpoints for Tableau and frontend consumption
  • Visualization Layer: Tableau dashboards for aggregated insights

Each layer operates independently, improving maintainability and making the system easier to extend or debug.

Analytics & Visualization

Tableau was used to convert structured news data into meaningful insights. Key analyses include:

  • Daily and monthly news volume trends
  • Top publishing sources by article count
  • Most frequent keywords appearing in headlines
  • Article length distribution across sources

These visualizations allow users to identify content patterns, dominant topics, and emerging trends at a glance — directly aligning with the SRS requirement for aggregated news insights.

Challenges & Limitations

Several real-world challenges were encountered during development:

  • Inconsistent HTML structures across news websites
  • Mixed date formats requiring normalization
  • Dynamic and JavaScript-heavy pages limiting extraction
  • Language detection inconsistencies in visualization tools

These challenges highlighted the complexity of working with uncontrolled web data and reinforced the need for robust validation and fallback logic.

Installation & Execution

To run the project locally:

  • Install Python 3.10+
  • Install dependencies from requirements.txt
  • Configure MySQL database and credentials
  • Run the scraper in training or testing mode
  • Launch the Flask application
  • Connect Tableau via the Flask API

The modular design allows individual components to be tested independently.

Reflection & Learnings

InsightBot demonstrates how data science extends beyond modeling into systems thinking, data engineering, and interpretability.

The project reinforced the importance of:

  • Asking the right questions before writing code
  • Designing for imperfect, real-world data
  • Balancing automation with explainability

Ultimately, InsightBot is a practical example of how data science can transform unstructured information into actionable insight.
